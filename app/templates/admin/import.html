Import Questions from a Document

Upload a .docx or .pdf file. Each question must follow this format (blank line between questions):

Q: What is 5 + 3?
A) 6
B) 7
C) 8
D) 9
Answer: C
Explanation: 5 + 3 = 8.

Q: Round 4,827 to the nearest hundred.
A) 4,800
B) 4,830
C) 4,900
D) 5,000
Answer: A
Topic: Number & Operations
Difficulty: easy
  • Explanation, Topic, and Difficulty lines are optional.
  • Topic must exactly match one of the subject's existing topic names, or it falls back to the topic you choose below.
  • Difficulty must be easy, medium, or hard (defaults to medium).
  • Only text-based PDFs work — a scanned/photographed PDF has no extractable text.
  • Images: for .docx files, a picture placed directly above (or inside) a question is automatically attached to that question — no special formatting needed. This doesn't work for .pdf uploads; add an image afterwards from the question's Edit page if needed.
  • Nothing is saved until you review a preview and confirm the import.

Want a ready-made example to start from? See samples/sample_questions.docx and samples/sample_questions.pdf in the project folder — both are pre-filled with two correctly formatted example questions.
